# Datasets

## Used
| Dataset | Use | Status |
|---|---|---|
| **TripWise sample dataset v1** (`datasets/build_sample_data.py` → `datasets/processed/*.json`) | destinations, attractions, accommodation, origins, transport links | Generated by us. **Illustrative**: approximate coordinates, estimated fees, *fictional* stays, fares from a documented distance model (`distance_model_v1`, see `meta.json`). Labelled as sample in API responses and UI. |
| **Stravl-Data** `Stravl_Travel_Preference_Data.csv` (https://github.com/Stravl/Stravl-Data) | optional ML (predict yes/no swipe) | Inspected and loaded. Raw CSV is git-ignored; see `datasets/raw/STRAVL_README.md` for its licence/terms (check before redistribution). 250,000 training and 80,000 test pairs after dropping "maybe" swipes. |

## Sample dataset schema (JSON)
- destinations: id, name, state, region, type, lat, lon, climate, best_seasons, min_days, max_days, tags, accessibility, wiki, description
- attractions: id, destination_id, name, tags, lat, lon, duration_min, fee_inr, intensity (1-3), accessible, best_slot, significance, description
- accommodation: id, destination_id, name, tier (hostel/budget/homestay/midrange/premium), price_inr, price_unit (per_bed/per_room), capacity, amenities, comfort, accessible, lat, lon
- transport_links: origin, destination, mode, distance_km, price_inr, price_basis (per_person/per_vehicle), duration_h, comfort, basis
- Validation (`data_loader.py`): drops invalid or duplicate records, checks the India bounding box (lat 6–38, lon 67–98), reports issues via `/api/meta`.

## Not integrated, and why
Wikivoyage listings, Kaggle tourism datasets, Open Travel Data and Hugging Face travel datasets were **not** integrated: they were not reachable from the build environment (outbound access is allow-listed) or the attach request was declined. Nothing from them is claimed. Stravl itself has only 13 Indian cities, so it cannot supply destination data.

## Substitutions and consequences
Because real destination/price data was unavailable, a labelled sample dataset replaces it. Consequences: results demonstrate the algorithms, not real-world travel advice; prices and availability must not be relied on.
